# Jeradesign Sgdk

## How do I install these formulae?

`brew install jeradesign/sgdk/<formula>`

Or `brew tap jeradesign/sgdk` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jeradesign/sgdk"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
